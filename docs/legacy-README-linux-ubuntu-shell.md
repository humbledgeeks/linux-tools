# linux-ubuntu-shell

Shell scripts and Docker Compose configurations for Ubuntu Server automation.

## Contents

| File | Purpose |
|------|---------|
| `ubuntu-docker-install.sh` | Automated Docker CE installation on Ubuntu |
| `docker-compose-immich.yml` | Docker Compose for Immich photo management |
| `hwaccel.ml.yml` | Hardware acceleration ML configuration |

## Prerequisites
- Ubuntu Server 22.04 or 24.04 LTS
- bash shell
- Root or sudo access
